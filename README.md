# 📓 Plataforma de orientación laboral 📓
## Objetivo
Desarrollar una aplicación web que ayude a las personas a descubrir sus habilidades, identificar sus fortalezas y orientar su desarrollo profesional mediante herramientas de autoconocimiento laboral y recursos para mejorar su empleabilidad.

El proyecto busca acompañar a personas que se sienten perdidas o desorientadas en el ámbito laboral, ofreciéndoles orientación para definir sus objetivos profesionales, mejorar su currículum y encontrar nuevas oportunidades.

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript
- Bootstrap
[Tecnologías adicionales por definir según la volución del proyecto]

## Alcance inicial
La primera versión permitirá a los usuarios conocer el proyecto, explorar recursos de orientación laboral y realizar una primera evaluación de sus habilidades e intereses profesionales.

También contará con un espacio para trabajar en la mejora del currículum y orientar al usuario en la identificación de posibles caminos profesionales.

A futuro, se contempla incorporar una comunidad, entrevistas en formato podcast con profesionales de diferentes sectores y nuevas herramientas de acompañamiento laboral.
